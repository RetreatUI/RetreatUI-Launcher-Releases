# RetreatUI Launcher Releases

Public binary release channel for the RetreatUI Launcher.

This repository contains compiled release assets only. The launcher source code remains private.

## Downloads

Use the newest release from the Releases page. Installed launchers from v0.2.6 onward can check this repository and update themselves automatically.

## Published assets

Each release contains:

- `RetreatUI_Launcher.exe`
- `RetreatUI_Launcher.exe.sha256`
- `RetreatUI_Launcher_win-x64.zip`
